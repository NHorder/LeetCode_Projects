# LeetCode Projects
## Introduction

The purpose of this project is to demonstrate my programming ability and reasoning deducation through the completion of LeetCode questions. Generative AI, such as ChatGPT, will not be used as part of this project unless explicitly stated. This is to ensure that demonstration of programming knowledge can be presented, and to prevent over-reliance on Generative AI for programming. 

This project contains two folders, LeetCode_C and LeetCode_Python, to demonstate and excerise the use of these programming languages. Each folder will contain sub-folders based on the question being answered, as they may involve multiple files / file access. Each sub-folder will contain a ReadMe.md document containing the question, and the related process conducted to answer the question.
