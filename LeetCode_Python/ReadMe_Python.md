# Python ReadMe
## Introduction

This folder contains the implementation of problems within Python, using Python 3.15.0 and the Jupyter Notebook Visual Studio Code Extension.

## Conventions

### Programming: Python Standard Conventions
- Variables use underscores
- Function names follow CamelCase

### Comments:
- '###' : The LeetCode question
- '##'  : Developer Notes
- '#'   : Developer Comment
- '#%%' : Jupyter Notebook Syntax  (Enables everything until next '#%%' to be run like a Jupyter cell)
